## Aug 7 2026 session — MSDSD, and a load-bearing architecture finding

Committed through **9cec13a**. Archive current, rollups current (rebuild after
any backfill — still manual). REVIEW.md was read and filtered (see below).

**MSDSD is in.** Mt Soledad mesonet (SDG&E), source 8, **559 m away** on the
same ridge, 187 ft lower, 10-min cadence. 3.8M observations, 2011-09-28 ->
2026-08-07, imported by `scripts/import_msdsd.py` from CSVs MXC pulled by hand
(Synoptic API 403s this network). It is **pure reference data — 0 canonical
rows, no priority rows.** Keep it that way (see finding below).

What it bought: the Zephyr hygrometer finally has a witness. Using temperature
as the control (Zephyr steadily +1.1..+2.2 F warmer = the elevation delta),
humidity error is provably instrumental: +13.7 (2011) -> +4.5 (2014) ->
**-44.2 (2016, catastrophic dry failure)** -> +4.1 (2017) -> +11.0 (2018).
**Hygrometer replaced NOVEMBER 2016**, dated from the data, not memory.
Healthy agreement = **±2 points** — a calibrated flagging threshold.

**★ THE FINDING: gap-fill via source_priority is ADDITIVE, not substitutive.**
`canonical_observations` partitions by exact `ts_utc`, so rank only arbitrates
between sources sharing an identical timestamp. Different clocks never collide,
so every row of a "lower-priority" source is simply added. Ranking msdsd LAST
still let it supply 65-75% of daily MINIMA and shifted 2011-2017 daily mean
temp by -0.46..-1.52 F. Reverted. **Do not add priority rows for a source on a
different sampling grid.** Same flaw is already live: wu_ksandi84 (2014) and
wu_ksandi354 (2016) warm those years by +0.24 / +0.63 F — still present.
Proper fix = interval-based fallback (use a secondary only across spans where
the primary is silent), which would also recover the 27 gap days correctly.
